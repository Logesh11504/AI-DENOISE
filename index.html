Project Brief

This project implements a Deep Learning-based Fingerprint Restoration system designed to reconstruct corrupted fingerprint images. Using a U-Net architecture, the model effectively removes Gaussian noise and fills in missing data—simulating real-world scenarios where fingerprints are smudged, incomplete, or grainy.

The system works through an Encoder-Decoder process: it first extracts high-level structural features from noisy inputs, then utilizes skip connections to preserve fine ridge details during reconstruction. Trained via a custom data generator that injects synthetic noise and occlusions, the model learns to map degraded images back to their original, clean ridge patterns with high fidelity.
