Project Brief

This system uses a lightweight TFLite CNN model to restore ridge continuity in corrupted fingerprints. By removing Gaussian noise and repairing missing "thick grains" (occlusions), it enables standard matching algorithms to function even on poor-quality latent prints.

Model Latency ~45ms
